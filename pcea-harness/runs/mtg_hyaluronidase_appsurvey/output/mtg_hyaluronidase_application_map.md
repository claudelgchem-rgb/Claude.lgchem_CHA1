# mTG · Hyaluronidase 적용처(Application) IP 조사·카테고리화

> **목적:** mTG와 Hyaluronidase의 IP를 **가장 대표적 용처를 제외**하고 전수 조사하여, 각 효소가 **어떤 적용처로 활용될 수 있는지 카테고리화**한다.

# 한눈에 — 적용처 카테고리 맵 (핵심 답)

## mTG (microbial transglutaminase) — ADC 제외 시 활용 가능 적용처
mTG의 본질 기능 = **단백질의 Gln–Lys 사이 ε-(γ-glutamyl)lysine 이소펩타이드 가교(crosslink)**. ADC를 빼면 적용처는 6대 군:

| # | 대분류 | 세부 적용처 | 성숙도 |
|---|---|---|---|
| M1 | **식품** (최대 비ADC 용처) | 유제품(치즈 수율·요거트·발효유·MPC), 육·어육 재구성/수리미, 식물성/대체단백 텍스처링, 두부, 비건치즈, 달걀/젤라틴 겔·식용필름·마이크로캡슐, 제빵/면 | 성숙 |
| M2 | **의료·바이오소재** | 수술용 실란트/지혈제(젤라틴-mTG 글루), 조직공학 스캐폴드/임플란트, 약물전달 가교젤·데포, 3D 바이오프린팅 바이오잉크, 세포 캡슐화, 상처치유/피부 | 성숙(실란트)~신흥(바이오잉크) |
| M3 | **비-ADC 바이오컨주게이션** | 단백질·펩타이드 PEG화/반감기 연장, Q-tag 부위특이 표지(형광/비오틴/킬레이트), 단백질-단백질·백신 접합, 효소/단백질 고정화·산업 생체촉매 | 성숙(PEG화)~신흥 |
| M4 | **진단·바이오센서** | 항체 부위특이 표지(검출시약), 배향 고정화 바이오센서 표면, 고정화 mTG 리액터 | 화학은 성숙, 센서표면은 신흥 |
| M5 | **산업·소비재** | 양모/실크 방축·키틴/케라틴 보강(섬유), 가죽 카제인 피니싱, 화장품/모발(컨디셔너 그래프팅·영구 스트레이트닝), 종이/접착제/바이오플라스틱(주로 학술) | 니치~신흥 |
| M6 | **펫푸드·사료** | 양식어 사료 펠릿 경화/수중안정성, 재구성 펫 트릿, 합성/배양육 펫푸드 | 니치~신흥 |
| (참고) | **백색 공간** | 비치료 구강/치과(타액 펠리클 가교) — 확정 mTG 제품특허 사실상 부재 → 신규 진입 여지 | 전(前)상업 |

## Hyaluronidase — SC 공동제형 제외 시 활용 가능 적용처
HAase의 본질 기능 = **히알루론산(HA) 분해 → ECM/간질 투과성↑, 분산↑, HA 제거**. SC 공동제형을 빼면 8대 군:

| # | 대분류 | 세부 적용처 | 성숙도 |
|---|---|---|---|
| H1 | **종양 간질(ECM) 분해** (최대 비SC 용처) | PEGPH20 전신IV 종양 HA 분해(항암제/면역항암 침투↑), 종양내 투여, HAase 발현 CAR-T·종양용해 바이러스 | 성숙(PEGPH20)~신흥(세포/바이러스) |
| H2 | **미용/피부 — HA 필러 용해** | 과·오주입 필러 교정/용해, 합병증 관리, **필러 유발 혈관폐색(실명) 응급 역전** | 임상은 大, IP는 니치 |
| H3 | **안과** | 유리체 액화/약물적 유리체용해, 유리체출혈 청소, 점탄물질 IOP 스파이크 완화 | 니치 |
| H4 | **국소·부위마취 보조(spreading factor)** | 마취제 확산·발현 촉진(안과 블록 등) | 임상 성숙, IP는 prior-art |
| H5 | **부종·림프부종·섬유화** | 림프부종, 뇌부종/두개내압, 공피증/켈로이드·반흔, 셀룰라이트, 상처치유 | 신흥~니치 |
| H6 | **심혈관** | 심근경색 경색크기 축소(infarct salvage), 혈전용해 보조 | 니치/휴면 |
| H7 | **생식의학(IVF)** | 난구세포 제거(난자 denudation), HA 결합 정자선별(PICSI/HBA) | 성숙(임상관행) |
| H8 | **정형·CNS·비뇨·수의·진단** | 추간판 화학수핵용해(디스크), 척수 유착/뇌부종, 페이로니, 소 유방염(수의), HA 정량 시약/동반진단 | 니치 |
